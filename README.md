# AG-TECH Calc 🧮

A modern and responsive scientific calculator built using HTML, CSS, and JavaScript. AG-TECH Calc provides both basic and advanced mathematical operations with a clean user interface, calculation history, and customizable themes.

## 🚀 Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)

- Scientific functions
  - Sin, Cos, Tan
  - Logarithm (log)
  - Natural Logarithm (ln)
  - Square Root (√)
  - Exponents (xʸ)
  - Factorial (x!)
  - Pi (π) and Euler's Number (e)

- Calculation History
- Degree/Radian Mode
- Multiple UI Themes
- Responsive Design
- User-Friendly Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
